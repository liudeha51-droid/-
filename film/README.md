# HOLLOW FAITH — EPISODE:00 (60s teaser)

An EVA-style 60-second short for *Touhou: Hollow Faith*, generated entirely in code:
frames drawn with Pillow, soundtrack synthesized with numpy, encoded with ffmpeg.

- `hollow_faith_ep00.mp4`: the film (1280×720, 24 fps, H.264 + AAC, 60 s)
- `contact_sheet.png`: one frame from each scene
- `render_eva_short.py`: renders both (`pip install pillow numpy`, then `python3 film/render_eva_short.py`; takes about 2 minutes)
